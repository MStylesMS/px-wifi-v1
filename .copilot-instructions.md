# px-wifi-v1 — AI Instructions

## Purpose

**Generic WiFi Prop Controller** — A battery-powered, WiFi-connected prop controller for escape rooms. Uses an ESP32-S3 with configurable I/O via wiring harness. v1.0 firmware implements a **wire defusal puzzle** with countdown timer, buzzer, and 7-segment display.

## Build & Flash

```bash
# From this directory:
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

Or use the ESP-IDF VS Code extension buttons.

## Dependencies

Shared components from `../px-components/`:
- `px_system` — Core system init and event loop
- `drv_rgb_led` — RGB LED driver
- `board_devkitc1` — Pin definitions (prototype; will switch to `board_px_wifi` for custom PCB)

The `CMakeLists.txt` sets `EXTRA_COMPONENT_DIRS` to `../px-components`. Override with `PX_COMPONENTS_DIR` env var.

## Wire Defusal Puzzle (v1.0)

- **Game states:** IDLE → ARMED → COUNTDOWN → DEFUSED / DETONATED
- **Inputs:** 4 wire GPIOs + lid switch
- **Outputs:** 7-segment display (I2C), piezo buzzer (PWM), status RGB LED
- **MQTT zone:** `wire-defusal` (configurable)
- **Commands:** start, stop, pause, resume, reset, setTime, setSequence, setPenalty
- **Events:** lidOpened, wireDisconnected, defused, detonated, penaltyApplied, stateChanged, timerSync

See `docs/functional-spec.md` for complete details.
