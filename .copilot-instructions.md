# px-wifi-v1 — AI Instructions

## Purpose

**Generic WiFi Prop Controller** — A battery-powered, WiFi-connected prop controller for escape rooms. Uses an ESP32-S3 with configurable I/O via wiring harness. v1.0 firmware implements a **wire defusal puzzle** with countdown timer, buzzer, and 7-segment display.

## Build & Flash

```bash
# From this directory:
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

Or use the ESP-IDF VS Code extension buttons.

## VS Code ESP-IDF Scope

- This directory is an ESP-IDF app project root and should be treated as an independent build context.
- Use this folder's context for Configure/Build/Flash/Monitor operations.
- Keep project-specific extension settings in `px-wifi-v1/.vscode/settings.json` (for example `idf.port`, target-related vars, and tooling paths).
- Do not assume settings from the umbrella `esp32/` root are sufficient for this project.
- If multiple apps are open in one workspace, verify `px-wifi-v1` is the selected ESP-IDF project before running commands.

## Serial Port Conflicts

Before flashing, always kill any open serial monitors/terminals that would block the flash tool:

```bash
# Kill any stray serial monitor or esptool processes
pkill -f "idf.py monitor" || true
pkill -f "screen.*usb" || true
pkill -f "minicom" || true
```

If using VS Code integrated terminal with a monitor open, close that terminal tab first.

- `drv_rgb_led` — RGB LED driver
- `board_devkitc1` — Pin definitions (prototype; will switch to `board_px_wifi` for custom PCB)

## Wire Defusal Puzzle (v1.0)

- **Game states:** IDLE → ARMED → COUNTDOWN → DEFUSED / DETONATED
- **Inputs:** 4 wire GPIOs + lid switch
- **Outputs:** 7-segment display (I2C), piezo buzzer (PWM), status RGB LED
- **MQTT zone:** `wire-defusal` (configurable)
- **Commands:** start, stop, pause, resume, reset, setTime, setSequence, setPenalty
- **Events:** lidOpened, wireDisconnected, defused, detonated, penaltyApplied, stateChanged, timerSync

See `docs/functional-spec.md` for complete details.
